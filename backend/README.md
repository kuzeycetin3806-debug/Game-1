# sehir-nefes-api

Cloudflare Worker that writes the newspaper and citizen letters for *Şehir Nefes Alıyor*
with the Anthropic API. The game works fully without it (template text); this only makes
the prose richer.

- `POST /v1/newspaper`, `POST /v1/letter` — structured facts in, JSON text out (see `src/schemas.ts`).
- `GET /v1/health`
- Header `X-Device-Id: <32 hex>` (random per install, generated by the game).
- Input is strictly validated; players never send free text. Output is re-validated
  (lengths, no links/markup). Any non-200 → the game uses its templates.
- Per-device daily limit (`DAILY_LIMIT`, KV `RATE`) and a response cache (KV `CACHE`).
- Model from `MODEL` (default `claude-opus-5-5`), `effort: low`, JSON-schema output,
  cached system prompt, server-side refusal fallback (`fallbacks: "default"`).

## Deploy

```bash
npm install
npx wrangler kv namespace create RATE     # paste ids into wrangler.toml
npx wrangler kv namespace create CACHE
npx wrangler secret put ANTHROPIC_API_KEY # never in the repo, never in the game
npx wrangler deploy
```

Then set the Worker URL in the game: `data/config/backend.json` → `"url"` and `"enabled": true`.

## Develop

```bash
npm test          # vitest, fake Anthropic client + in-memory KV
npm run typecheck
npx wrangler dev  # local; put ANTHROPIC_API_KEY in backend/.dev.vars (gitignored)
```
